## ✨ 特性一览

### 📥 导入

- 支持**本地文件夹**与 **ZIP / CBZ / RAR / CBR** 压缩包，可多选、可直接**拖拽进窗口**
- **批量导入**：选择一个根目录，每个子文件夹 / 压缩包自动作为一本漫画
- **库目录记忆**：批量导入过的根目录会被记住，启动时自动扫描，新丢进去的漫画直接上架
- 识别 `jpg` `jpeg` `jfif` `png` `webp` `gif` `avif` `bmp`，页码**自然排序**（`1, 2, 10` 而非 `1, 10, 2`）
- 自动提取第一页生成封面缩略图；按路径去重；单项失败不影响其余项

### 📚 书架

- **虚拟滚动网格** —— 数千本漫画依然流畅，DOM 中始终只有可视区的几十张卡片
- 搜索（`Ctrl+F`，输入防抖）、排序（最近阅读 / 名称 / 导入时间）、卡片大小三档
- 卡片显示封面、页数、阅读百分比、最近阅读时间；**来源丢失**自动标记
- **多选与批量操作**：`Ctrl+点击` 加选、`Shift+点击` 连选、`Ctrl+A` 全选，批量设置分类 / 重新扫描 / 重新定位 / 移除
- **重命名**：书架标题可随意改（压缩包名常常带一堆前缀），磁盘上的原文件不动
- **来源重定位**：整库从 D: 搬到 E: 后，选一次新根目录就能按文件名批量改绑，**阅读进度、分类与书签全部保留**
- 右键菜单：从第一页开始 / 重命名 / 重新扫描 / 打开所在位置 / 移除
- 移除只删记录，**永远不动原文件**

### 📖 阅读器

- **单页 / 双页 / 连续滚动**三种模式，随时切换（`1` `2` `3`）
- **双页模式**：第一页（封面）可单独占屏，横向**跨页大图自动铺满整屏**，不再被塞进半个视口
- **适应宽度 / 适应高度 / 原始大小** + 自由缩放（25%–400%，`Ctrl+滚轮`）
- **从左到右 / 从右到左**阅读方向（日漫友好，双页自动交换左右）
- **书签**：`B` 收藏当前页，顶栏一键跳转（可在设置里关闭入口）
- **缩略图跳页条**（`T`）：横向缩略图带虚拟滚动，长篇也不卡
- **自动裁白边**（`C`）：扫描版四周的纯色留白自动去掉，「适应宽度」量的是真正的内容
- **亮度调节**：夜里看白底扫图不刺眼（只作用于漫画页，工具栏保持原色）
- **自动翻页**（`A`）：间隔可调，翻到尽头自动停
- 相邻页**提前解码**，翻页零白屏；滚动模式只挂载视口附近页面，长篇不占内存
- 工具栏自动隐藏、点击左右分区翻页、**鼠标侧键翻页**、放大后**按住拖拽平移**、滚轮到页面边缘才翻页
- 全屏阅读（`F`）、进度滑块、**页码直接输入跳转**
- 翻到最后一页会提示，**再翻一次直接返回书架**

### 💾 进度与数据

- 每本漫画独立记住**页码 + 阅读模式 + 缩放 + 方向 + 双页偏移 + 裁边开关**，重新打开自动续读
- 全局设置：主题、默认阅读模式与缩放、亮度、自动翻页间隔、侧键翻页、启动时打开上次阅读……
- **备份与恢复**：一键把书架、分类、进度、书签与封面导出到文件夹；换电脑时可**合并导入**或**覆盖恢复**
- 数据结构**版本化 + 自动迁移**，升级应用不丢数据（迁移前自动备份）

### 🧩 扩展功能

- 设置中可按需**开启 / 关闭**的可选功能，关闭只隐藏入口，**数据不会删除**
- **自定义分类**：创建 / 重命名 / 换色 / 删除分类，一本漫画可同时属于多个分类
- **书签**：阅读器里的收藏与跳转入口

## 📦 安装

到 [Releases](https://github.com/AuraYoona/comic-reader/releases) 页面下载：

| 文件                            | 说明                             |
| ------------------------------- | -------------------------------- |
| `ComicReader-Setup-x.y.z.exe`   | 安装版，可选安装目录，含卸载器   |
| `ComicReader-x.y.z.exe`         | 便携版，免安装单文件，随处运行   |

用户数据保存在 `%APPDATA%/comic-reader/`，卸载重装不丢失：

```
library.json        漫画列表、分类、阅读进度、书签、全局设置（原子写入，损坏自动备份重建）
covers/             封面缩略图
window-state.json   窗口大小与位置
logs/main.log       主进程日志（>2MB 自动轮转）
```

> `library.json` 不带缩进：上千本时能省掉一半体积与写入量。想留一份可读的副本，用设置里的「导出备份」。
>
> `logs/main.log` **不记录漫画标题与完整路径**：日志里只有 id 前 8 位和「盘符 + 目录层数 + 扩展名」这样的脱敏路径（如 `D:\…2层\*.cbz`），贴到 issue 里求助不会连书架内容一起暴露。界面上的提示仍显示完整信息。

### 关键设计

| 问题                 | 方案                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| 大图传输卡顿         | 图片**不走 IPC**：主进程注册 `comic://` 协议，`<img>` 按页请求，磁盘/压缩包字节直接流式返回        |
| 翻页白屏             | 相邻页用 `img.decode()` **预解码**进 Chromium 图像缓存（LRU 32 张，淘汰即中断请求）                |
| 长篇滚动爆内存       | IntersectionObserver 只挂载视口 ±2 屏，远处卸载并保留占位高度                                      |
| 书架万卡渲染         | 自研虚拟网格：封面固定 3:4 + 标题固定两行 → 行高精确可算，只渲染可视行                             |
| 压缩包反复开销       | 按格式分派的适配器 + 通用句柄 LRU（ZIP 4 个 / RAR 1 个，空闲自动关闭，并发打开合并成一次）         |
| RAR 支持要装原生模块 | 用纯 WASM 的 `node-unrar-js`，打包无需编译；wasm 显式读入内存交给库，绕开 asar 定位问题            |
| 翻页把整库写爆       | 进度更新走 5 秒长防抖并与结构性改动分档（最早截止时间生效），退出前 `flushSync` 兜底，进度不会丢   |
| 封面是几 MB 的原图   | nativeImage 解不了 WebP/AVIF 时先原样落盘，再由渲染进程用 canvas 压成 480px JPEG 回传替换          |
| 跨页图被压成一半     | 图片加载后按宽高比判定，跨页图独占整屏并让后续配对顺延                                             |
| canvas 被跨源污染    | 裁边与封面重压走 `fetch` + `createImageBitmap`；`comic://` 开 CORS，但 ACAO 只发给本应用自己的来源（打包后的 `file://` 与开发地址），其余一律拒绝 |
| 整库搬盘丢进度       | 在新根目录下按文件（夹）名匹配（同名时比对父目录），只改写 `sourcePath`                            |
| 数据安全             | 写临时文件再改名（原子性）+ 退出强制落盘 + 解析失败备份自愈 + 版本化迁移                           |
| 进程安全             | sandbox + contextIsolation + CSP + 拒绝一切导航/弹窗/Web 权限 + 封面路径越界防护 + 回传字节类型校验 |

## 🛠️ 开发

```bash
npm install
npm run dev          # 开发模式
npm run build:win    # 打包安装版 + 便携版

npm run lint         # ESLint
npm run format       # Prettier
npm run typecheck    # 主进程 + 渲染进程分别做类型检查
npm test             # Vitest（122 个用例）
```

CI 的质量门禁：`format:check` → `lint` → `typecheck` → `test` → `build`。
